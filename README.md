# Pokahi MMD Clip Merger

Unityで、変換済みの身体モーション・リップ・表情／目線を1本の `.anim` にまとめるエディターツールです。元ファイルは残して、新しいアニメーションを保存します。

**追加するのはブレンドシェイプ（顔の変形）のカーブです。眼球ボーンやHumanoidの目線カーブは統合しません。**

## 導入

1. [unitypackage](Packages/Pokahi-MMD-ClipMerger-0.1.0.unitypackage) をダウンロードします。
2. Unityの `Assets → Import Package → Custom Package` からインポートします。
3. `Tools → Pokahi MMD Clip Merger → モーション・リップ・表情を結合` を開きます。

ソースから導入する場合は `Assets/PokahiMmdClipMerger` フォルダーをプロジェクトのAssetsへコピーします。両方を入れる必要はありません。

## 使い方

1. 同じ曲・同じアバター向けに変換したアニメーションを用意します。
2. **身体モーション**にダンス、**リップ**に口、**表情・目線**に顔用のファイルを入れます。リップか表情はどちらか片方でも使えます。
3. 重複する表情がある場合は優先側を選びます。初期値はリップ優先です。
4. **結合して保存…**でAssets内に保存します。同名ファイルがあっても別名にして原本を残します。
5. 統合結果をAnimatorやワールドの曲登録ツールへ指定し、実際のアバターで口・まばたき・身体を確認します。

Projectで複数のAnimationClipを選び、ウィンドウの自動振り分けボタンも使えます。判定はファイル名による推測なので、各欄を確認してください。

## 仕組みと注意点

- 身体クリップを複製して、リップ・表情の `SkinnedMeshRenderer / blendShape.*` カーブだけを追加します。追加ファイルに含まれる身体の初期姿勢はコピーしません。
- 同じパス・同じブレンドシェイプのカーブは、優先側の**カーブ全体**で置き換えます。値が0のキーも有効です。顔の部位を名前から判定したり、値を足し算したりしません。
- 身体の動き・イベント・オブジェクト参照カーブを保持します。既存の顔カーブは追加側と重複すると置き換わります。
- キーの時刻・値・補間を再サンプリングせずコピーします。開始時刻や再生速度の自動調整はしません。fps設定は身体側を引き継ぎます。
- クリップの終了時間は最も長い入力に合わせます。短い身体モーションの後に、顔だけが続く可能性があります。
- メッシュの階層パスとブレンドシェイプ名が対象アバターと一致する必要があります。別アバターへの再対応付けは行いません。
- 眼球ボーン、Humanoidの目線、カメラ、VMD直接読み込み、プレビュー再生は対象外です。目線ファイルに顔カーブと眼球ボーンが混在する場合、顔カーブだけが追加されます。

## 動作環境

Unity 2022.3.22f1で検証。VRChat SDK・UdonSharp・Modular Avatarは不要です。
