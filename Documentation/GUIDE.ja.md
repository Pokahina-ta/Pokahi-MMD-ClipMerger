# 統合ガイド

## 最初に用意するもの

同じ曲の身体・リップ・表情の変換済みAnimationClipを用意します。3本とも同じモデル向けの変換設定を使ってください。元のVMDからの変換は、このツールを使う前に行います。

## 自動振り分け

名前に `lip` / `リップ` があるファイルを口、`face` / `eye` / `表情` / `目線` があるファイルを表情に振り分けます。それ以外が1本なら身体にします。複数候補があるときは手動で指定してください。

## 口が動かない・まばたきが消えた

重複カーブの優先設定を確認してください。リップファイルに「まばたき=0」のカーブが含まれると、リップ優先で表情側のまばたきも置き換わります。必要なら変換時に不要な表情出力を外すか、入力ファイルの不要なカーブを整理してください。原本を残して作業してください。

## ブレンドシェイプがないと表示される

変換時の表情の対応付けを確認してください。眼球ボーンだけのアニメーションはこのツールの対象外です。何も追加できない入力はエラーにして保存しません。

## 統合できたのに顔が動かない

Animationウィンドウで曲線の対象パスと対象アバターのメッシュ階層を比較します。パス・ブレンドシェイプ名は大文字小文字も一致させる必要があります。モデルが違うと再変換や対応付けが必要です。

## 音と合わない・終了が遅い

入力の時刻はそのままコピーされます。結合は同期ずれの修正ではありません。音源と入力モーションの開始時刻を確認してください。出力時間は最長の入力になるため、短い身体クリップの最後で身体だけが停止する場合があります。

## 保存結果を確認

冒頭・途中・終盤で身体、口、まばたきを確認してから使用先に登録します。元の3ファイルは自動削除されません。
