# 検証記録

Unity 2022.3.22f1の専用プロジェクトで、自作の検証用クリップを使用。

- 身体カーブを保持し、追加ファイルの身体・眼球ボーンのカーブを無視すること
- リップ／表情の重複優先を両方向で切り替えられること
- 顔カーブの時刻・値・接線を保持すること
- 身体のイベント・オブジェクト参照・fpsを保持すること
- 最長クリップの長さ、原本非変更、同名保存時の別名化
- 顔カーブなし、不正な保存先、入力不足の拒否
- 単体コンパイルとUnity標準のパッケージ書き出し

任意のモデルとの互換性、VRChat実機での再生はこの検証には含みません。
